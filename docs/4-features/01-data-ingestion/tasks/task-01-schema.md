# Task 01: .netryx Bundle Loader — Schema Validation & Extraction

## Target Files

- `utils/netryx_loader.py` (new)
- `tests/test_netryx_loader.py` (new)
- `tests/generate_fixtures.py` (new — synthetic test bundle generator)
- `tests/fixtures/` (new — generated fixtures)

## Description

Implement the core `.netryx` ZIP bundle reader. The loader must validate the archive structure, handle Optional PCA model (missing bundles fall back gracefully), and return a structured object containing all index components.

## Checklist

- [ ] Define `IndexBundle` dataclass (descriptors, metadata, pca, manifest)
- [ ] Implement `load_bundle(path) -> IndexBundle`
  - Open ZIP, validate it contains required files
  - Parse `manifest.json`, validate `format_version == "2.0"`
  - Load `descriptors.npy` with `mmap_mode='r'` for large indexes
  - Load `metadata.npz` entries into dict of numpy arrays
  - Load `pca_model.pkl` via pickle — catch `KeyError` if missing
  - If PCA missing: check manifest — if `raw_descriptor_dim != descriptor_dim`, use default PCA from config; else skip PCA
  - Log a warning when using fallback PCA
- [ ] Implement `extract_bundle(bundle_path, output_dir)` with filename mapping (`descriptors.npy` -> `megaloc_descriptors.npy`, `pca_model.pkl` -> `megaloc_pca.pkl`)
- [ ] Implement `validate_bundle(path) -> bool` for integrity checks
- [ ] Handle missing optional files gracefully (index_info.txt, pca_model.pkl)
- [ ] Test with synthetic fixture (generated by `tests/generate_fixtures.py`)
- [ ] Test with missing PCA model (ensure fallback path works)
- [ ] Add error handling for corrupt ZIP, missing files, version mismatch
